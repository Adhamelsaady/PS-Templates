Competitive Programming Technique Book

The source files contain reusable algorithms and data structures. Each file starts with comments explaining the problem, how to use the code, the important variables, the main idea, the complexity, and any necessary terminology.

Suggested order:
1. CP template
2. Prefix sums, modular counting, and XOR tricks
3. MEX, selection, and greedy coverage
4. Monotonic stack and binary-matrix techniques
5. Dynamic programming
6. Ordered sets, multisets, and dynamic frequency structures
7. Graph and bitmask techniques
8. Advanced number theory
9. Combinatorics and constructive algorithms

The .idea directory contains IDE settings and is not part of the algorithms.
